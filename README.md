# UARC Sensor Board

## Overview
Sensor board used for UARC applications. 

## Functional Blocks
- MCU
- Inertial Measurement Unit (IMU)
- Barometric pressure sensor
- Accelerometer
- Global Navigation Satellite System (GNSS)
- CAN Bus and Transceiver
- Debug / Programming interface
- SD Card connector


## Repository Contents
- Altium schematic (`.SchDoc`)
- PCB layout (`.PcbDoc`)
- Project files (`.PrjPcb`)
- Custom and generic libraries (`Library/`)
